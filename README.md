# Flux

最新发布版见 [Releases](https://github.com/shigurewu/Flux/releases/latest)，改动记录见 [更新日志](CHANGELOG.md)。

**个人自用**的贴吧客户端，基于 [FluxTie](https://github.com/makise2060/FluxTie)（上游基于 [TiebaLite](https://github.com/huanchengfly/tieba-post)）做的一点个性化修改。

说清楚一点：**这个仓库几乎就是原版**。功能、架构、界面绝大多数都来自上游，我只是在少数几个自己用着不太顺手的地方做了小改动，图个顺手而已。不是要另做一个客户端，也不打算维护成一个产品，更不建议拿它当主力推荐给别人。

想要更完整、有人正经维护的版本，请直接去 [FluxTie](https://github.com/makise2060/FluxTie)。

> 非官方第三方客户端，与百度 / 贴吧官方无关。

## 与原版的关系

- 个人基线：1.3.13（`d73829a7`），当前 **1.3.19**；最初基于上游 `v1.2.0`（`edf61d0`）
- 1.3.17 选择性接入上游至 `4956c452` 的部分功能与修复，保留个人版排版、消息列表与刷新交互
- 改动逐条列在 [`CHANGELOG.md`](CHANGELOG.md)；后续跟版应逐项比对，避免覆盖个人界面与交互

如果上游合了其中某些改动，这个仓库随时可以放弃对应补丁、直接跟上游。

## 相对原版改了什么

下面保留个人版原有修改的介绍；1.3.17 起从上游选入的修复见上方更新日志：

### 帖子页

- 底栏改为「左：头像 + 评论框；右：点赞 / 评论 / 收藏」，不再有 ⋮（菜单保留在顶栏）
- 点评论框不跳转，在本页弹出**快捷回复面板**：跟随键盘上移，点外部 / 返回键 / 发送成功都会收起，并防重复提交
- 主楼排版单独调过：标题 18sp / 字重 600 / 行高 1.35；正文**按容器宽度动态定字号**（≈可用宽度 ÷ 19，夹在 13.5–16sp），行高 1.7、字距 0，按换行拆成独立段落
- 关掉 Android 原生字体内边距（`includeFontPadding = false`）+ 行高居中裁剪，行距视觉更均匀
- Android 10+ 尝试可变字重 350，系统字体不支持时回落 400
- 标题以全角左括号或引号开头时做**悬挂标点**，让第一个汉字与正文左对齐
- 楼中楼从外部进入定位到阅读区 30% 位置，并有一次中性灰呼吸高亮
- **楼中楼图片可点开**：缩略图直接进大图查看器，左右滑动切换同楼层图片
- 点赞数显示为净分值（`+12 / -3 / 0`）
- 列表触底显示「已经到底了」，并保留额外拉出间距

### 深色与阅读

- **深色模式柔和文字**：深色下正文用 `#A8A8A8`、次级文字 `#8A8A8A`，不再是大面积纯白；外观设置里可一键关掉，恢复主题原色
- 1.3.17 在原有 Material `onSurface` 基础上，补齐默认内容色、导航和深色容器前景、帖子标题及原生编辑框；仍需在实际设备逐页确认视觉效果

### 信息流

- 卡片头部显示**所在吧**（原版贴吧风格）：吧头像、吧名（自动补「吧」后缀）、关注人数与贴子数；可在设置里切回作者模式
- 图片按真实宽高比展示，同时限制单图高度，整页截图不会占满一屏
- 摘要固定 3 行、行高 1.55，左对齐

### 动态页的刷新

这套刷新是**自己实现**的（`GlassPullRefresh` + `GlassRefreshIndicator`），没有沿用 Material 的 `pullRefresh`——两套位移叠在一起会互相打架、手感发飘。

- **手动下拉**：玻璃圆环从顶部拉出，达到阈值触发刷新，松手回弹；反向拖拽会先抵消下拉，不会误触发
- **再次点击底栏「动态」**：先平滑回顶 → 圆环拉下 → 旋转并刷新 → 浮出「刷新了 N 条」提示 → 收回。整条链路和手动下拉共用同一个刷新状态，同一时刻只有一套动画在动
- **底栏图标联动**：只有当「当前就在动态页」且「列表不在顶部」时，图标才临时变成刷新圆圈；离开动态页或回到顶部后恢复普通图标
- **从别的 Tab 切过来不刷新**：只有真正在动态页再点一次「动态」才触发。早期版本在这里会把历史状态误判成一次点击，导致切回来就莫名刷新，已修正
- **列表里的「上次阅读到此处，点击刷新」**：点击后回顶与刷新**并行**执行，列表立刻上滑、圆圈同时在顶部转，不再「先干等刷新结束、再突然位移」
- **消息中心有进程内缓存**：切回消息 Tab 不会重复请求，只有手动点刷新才重新拉取

### 消息

- 消息中心改为分类入口（回复我的 / 提到的我 / 赞我的），有未读显示红点，支持「全部已读」
- 分类列表为贴吧式条目：头像 + 昵称/时间 + 动作文案 + 引用块 + 吧名
- 设置里可「屏蔽小红点」

### 个人主页

- 帖子卡片改版：作者头像 / 昵称 / 时间在上，所在吧信息在下，右上角「更多」菜单
- 「公开 / 仅自己可见」常驻显示，判断改为与服务端完整公开列表核对，不再把未确认的帖子标成公开
- 删除帖子与修改可见范围收进「更多」菜单，各自单独确认
- 粉丝数、回帖数可点击，回帖直达回复列表；关注吧显示公开范围（公开 / 好友可见 / 仅自己可见）

### 其他零碎

- 应用内更新检查指向**本仓库**的 Release，可覆盖安装升级
- 发主题时可选「仅自己可见」
- 行内表情跟随正文字号缩放
- 备份排除账号数据、收紧明文流量

## 下载

从 [Releases](https://github.com/shigurewu/Flux/releases/latest) 下载最新的 `Flux-vX.Y.Z.apk` 直接安装。

- 应用内也带更新检查（设置 → 关于 → 检查更新），检查的是**本仓库**的 Release
- 首次应用内安装需要允许「安装未知应用」
- 如果某次更新装不上，可以先用浏览器下载 APK 手动装一次

## 构建

环境要求：

| 项 | 版本 |
|---|---|
| JDK | 17 |
| Gradle | 9.7.1（仓库自带 wrapper） |
| Android SDK | compileSdk 37，build-tools 36.0.0 |
| Kotlin | 2.3.x |

```bash
# 1. 准备 local.properties（不要提交）
echo "sdk.dir=/path/to/android-sdk" > local.properties

# 2. 准备签名（不要提交）
cat > keystore.properties <<'EOF'
keystore.file=your.jks
keystore.password=******
keystore.key.alias=your_alias
keystore.key.password=******
EOF

# 3. 构建
./gradlew :app:assembleRelease
```

产物位于 `app/build/outputs/apk/release/`。
