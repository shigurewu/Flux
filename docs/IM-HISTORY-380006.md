# 1.3.19-im.6：保留历史接口错误说明

内部版本号 66，基于 im.5。这是诊断更新，不代表已修好历史同步。

用户实机截图确认：手动同步收到服务端错误码 380006，没有取回历史消息；同一截图中发送的文字与内置表情能显示。仅凭该错误码不能推断账号没有历史、登录过期、接口停用或固定某个参数错误。

检查发现 im.5 解析错误时只保留编号，丢弃了 error_msg / error.errmsg。本版把服务端提供的说明显示在编号之后，缺少说明时明确提示。没有更换接口、猜测命令号、自动轮试客户端版本或重置实时私信游标。

说明仅取错误文本，不显示完整响应。已知当前请求凭据、链接、邮箱、长令牌以及控制字符会隐藏或移除，文本限制 160 字符；不记录原始响应或请求。新增测试验证顶层/嵌套错误说明、凭据隐藏和异常字段类型。

本地无登录态与固定无效测试登录态的只读探测：使用带签名请求，分别以表单和查询参数方式提交，都得到 error_code=1、“用户未登录”。未能复现实机的 380006，因此此时尚未确定其具体含义。公开代码与错误码检索未找到可靠定义。

安装后，在原聊天再点击“同步历史消息（尝试）”，查看 380006 后是否出现服务端说明。若仍未提供说明，需要进一步核对真实接口约定，不能把错误当作空历史。无需向开发者提供 BDUSS、Cookie、密码或完整聊天响应。

接口原始调用依据和历史导入边界见 [历史读取尝试说明](IM-HISTORY-EXPERIMENT.md)。
