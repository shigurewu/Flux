# Flux 1.3.19 整合版

版本名 1.3.19，内部版本号 68，包名 com.shigurewu.flux。以当前包含 im.7 的工作源码为基础，保留前序非私信更新，统一关闭私信功能；不回退到旧版源码。已有本地聊天记录保留。

## 本版内容

- 个人主页：作者/时间卡片头部、吧头像补取、更多菜单、删除确认、公开/仅自己可见双状态，以及完整公开帖子列表核对和未知状态重试。
- 关注吧：公开、好友可见、仅自己可见范围处理；隐私管理提供官方设置指引。
- 动态：推荐/关注/热门统一玻璃刷新圆环，只响应当前可见页；防重叠请求、快速完成收圈、横向及反向手势修正。
- 我的：粉丝和回帖数字可点击，回帖直达回复标签；粉丝独立模型解析、分页和失败重试。
- 表情与外观：行内小表情与当前字号一致；保留帖子正文排版和深色柔和文字，补齐此前覆盖路径。
- 保留 1.3.17 选择性整合的设置搜索、吧内热门、置顶/吧规折叠、阅读位置恢复、通知及更新流程修正。

## 私信停用范围

`PrivateMessaging.enabled=false` 是固定构建开关。消息页和用户资料页隐藏私信入口；会话、折叠消息、聊天页受开关保护，聊天深链接只显示暂未开放。私信会话流返回空列表，不计入底栏未读提示。

应用启动不注册私信连接流程；管理器启动、消息拉取、发送、已读回执和历史请求都有开关保护。聊天列表和 ViewModel 也不会执行私信加载操作。

协议、存储、表情输入、折叠消息和历史尝试代码保留在源码中，供以后继续研究；发布包允许正常优化移除不可达代码。没有删除用户数据，也不把未打通的历史读取作为发布功能。

## 安装与验证范围

内部版本号高于之前 im.1–im.7，签名沿用现有签名，可覆盖安装这些版本。安装包、源码和校验清单配套交付，源码不包含签名密钥、本机配置或构建缓存。

验证包括现有单元测试、发布构建、Lint Vital、APK 包名/版本/签名、源码一致性，以及私信停用入口与调用链检查。

没有新增真实账号或手机全流程验收。粉丝接口在实际账号上的最终效果、主页公开范围与官方结果的一致性、深色视觉和刷新触感仍需实际使用确认；本版版本名去掉测试后缀不代表这些项目已经完成真机验证。
